# addons.mozilla.org listing

Copy these fields into the listing on addons.mozilla.org.

## Summary

Press Ctrl+Insert and type to fuzzy-search your open tabs by title or address, across all windows. Use the arrow keys to pick a result, Enter to switch to it, or Delete to close it. Recently used tabs come first. Collects no data.

## Description

With twenty tabs open, the titles blur together and the one you want is hard to spot. **Tab Filter finds it in a few keystrokes.**

Press **Ctrl+Insert**, type a few letters, and press **Enter**.

- **Fuzzy search:** type `gs` to find "GitHub Status", or `wkmd` to find "Wikimedia". Words can come in any order.
- **Best matches first:** exact matches in the title rank highest, then matches in the address, then fuzzy matches. Matched letters are underlined.
- **Recent tabs first:** with an empty search, Ctrl+Insert then Enter returns to the tab you just left.
- **Every window:** tabs from other windows, such as installed web apps, are labelled "other window".
- **Tidy up as you go:** press **Delete** to close the selected tab without leaving the list.
- **Tell similar tabs apart:** the selected result shows its full address.

To change the shortcut, open `about:addons`, click the gear icon and choose **Manage Extension Shortcuts**.

**Privacy:** Tab Filter reads tab titles and addresses only to show the list. It stores nothing and sends nothing anywhere.

Source code and issues: https://github.com/svandragt/tab-filter
